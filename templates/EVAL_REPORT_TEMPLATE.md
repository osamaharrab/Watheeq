# Evaluation report

Generated by `python scripts/run_eval.py` after a local stack run.

The generated report must include the question checksum, generation time, all 48 question IDs, taxonomy classes, per-class outcome counts, expected-outcome results, citation-validity metrics, unsupported-assertion count, failures, and the ownership-slice/full-registry limitation. It must label answered counts as evaluation-question counts, report citation validity as N/A when no evaluation question is answered, and state that live smoke-test examples are excluded from the evaluation metrics. It must not contain invented metrics before the harness runs.
